# Working in this repository

This repository is **public**. Project skills in `.claude/skills/` define how to
work here; use them:

- `privacy-guard`: before any commit, push, PR, release, site deploy, or adding
  a fixture, report, screenshot or data file.
- `git-github-workflow`: branches, commit messages, versions, PRs. Never push
  unless the owner asks in the conversation; never commit on `main`.
- `repo-structure`: where files go; nothing new at the repo root.
- `research-report`: data sources, method, verification and PDF/CSV deliverables
  for studies.

Personal files live in the git-ignored `private/` folder. Runtime user data in
`backend/data/` is never read into tracked files.
